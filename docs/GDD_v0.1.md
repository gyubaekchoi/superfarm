## 1. 한 줄 컨셉

> **"밭 사이를 달리기만 하면 저절로 수확되고, 팔면 돈이 튀고, 그 돈으로 밭이 넓어진다."**
> 피자레디의 '걸으면 다 되는' 조작감 + 체인소 주스킹의 '도구가 강해지는' 성장 쾌감을 농장 타이쿤에 이식.

### 핵심 재미 3가지 (와우 포인트)

1. **손 안 대고 수확** — 밭에 다가가면 자동으로 우수수 수확, 머리 위로 작물이 쌓이는 시각적 만족.
2. **폭발 강화** — 강화는 항상 여러 단계가 한 번에 뛰어오르는 "몰아치기" 방식. 숫자가 롤링되고 파워가 갑자기 치솟는다.
3. **첫 뽑기의 짜릿함** — 첫 뽑기는 의도적으로 고등급 확정. 5분 만에 캐릭터가 확 달라지는 걸 체감.

## 4. 핵심 메카닉 상세

### 4-1. 이동 & 자동 수확

- 캐릭터 기준 **수확 반경 R** (기본 4 studs). 반경 내 '성장 완료' 작물은 자동 수확.
- 수확 처리 간격 = **수확속도 스탯**. 기본 0.25초/개 → 최대 0.05초/개.
- 수확 시 작물이 포물선으로 튀어 머리 위 스택에 안착. 스택은 좌우로 살짝 흔들림(피자레디 감성).
- 운반 한도 도달 시: 스택 위에 🚫 아이콘 + 짧은 진동, 더 이상 수확 안 됨 → 판매대로 유도 화살표.
- 이동속도 기본 16 → 업그레이드/장비로 최대 32.

### 4-2. 작물 성장

- 성장 3단계 시각화: 🌱 새싹 → 🌿 중간 → 🌾 완성(살짝 빛남, 위아래 바운스).
- 완성 상태만 수확 가능. 수확 후 즉시 새싹으로 리셋.
- 구역별 성장 시간·가격은 §7 경제표 참고.

### 4-3. 운반 & 판매

- 판매대(🏪) 근접 시 스택이 0.08초 간격으로 자동 투입.
- 투입된 작물 수 × 단가 = 코인이 판매대 앞 바닥에 **물리 오브젝트로 흩뿌려짐**.
- 코인은 캐릭터 근접 시 자석처럼 빨려 옴. 획득 사운드는 연속 획득 시 피치가 계단식으로 상승(슈퍼센트 시그니처).
- HUD 💰 숫자는 롤링 애니메이션.

### 4-4. 업그레이드 패드 (월드 오브젝트)

- 패드 위에 서 있으면 코인이 캐릭터에서 패드로 **줄줄 흘러 들어가는 연출** + 원형 게이지.
- 부족하면 부분 충전 상태 유지 → 다음 방문 목표.
- 패드 종류
  - 👟 이동속도 (Lv 1~15)
  - 🌾 수확속도 (Lv 1~15)
  - 🎒 운반량 (Lv 1~15)
  - 🟫 밭 확장 (구역별 4단계)
  - 🤖 일꾼 고용 (구역별 최대 2명)
  - 🔒 다음 구역 게이트
- 표기: 아이콘 + 💰 + 숫자만. 글자 없음.

### 4-5. 일꾼 로봇 (자동화)

- 고용 시 해당 구역 밭을 느리게 왕복 수확·판매 (플레이어의 30% 효율).
- 플레이어 이탈 중에도 서버 내 존재 시 동작. 오프라인 수익은 MVP 제외(2차).
- 일꾼 패드에 코인 넣으면 속도 업그레이드 (3단계).

### 5-3. 🎁 뽑기 (가챠)

**획득 경로**: 레벨업 🎫, 💎(젬)로 구매, 일일 🎁 상자, Robux 상품.

**장비 슬롯 3종 (단일 풀)**

| 슬롯 | 효과 | ★1 | ★2 | ★3 | ★4 |
|---|---|---|---|---|---|
| 🪓 도구 | 수확속도 | +10% | +25% | +50% | +100% |
| 👟 신발 | 이동속도 | +10% | +20% | +35% | +60% |
| 🎒 가방 | 운반량 | +5 | +15 | +30 | +60 |

**확률 (기본)**: ★1 55% / ★2 30% / ★3 12% / ★4 3%

**의도적 초반 리깅 (와우 포인트)**

| 뽑기 회차 | 규칙 | 의도 |
|---|---|---|
| 1회차 (Lv2 무료) | **★3 확정** | 5분 만에 파워 급상승 체감. "이 게임 뽑기 좋다" 인상 |
| 2회차 | 일반 확률 | 대비 효과 |
| 3회차 | ★2 이상 확정 | 실망 방지 |
| 이후 | 10회 내 ★3 미획득 시 ★3 보장 (천장) | 장기 신뢰 |

- 리깅 뽑기는 **무료 티켓에만 적용**. Robux 결제 뽑기는 표기 확률 그대로 (정책 준수).
- 중복/하위 장비는 자동 분해 → 💎 강화석 (★1=1, ★2=3, ★3=10, ★4=30).
- **연출**: 상자가 흔들림 → 등급 색 빛기둥(회/초/파/금) → 장비 튀어나옴 → 장착 시 캐릭터 외형 즉시 변경(🪓가 커지고 빛남). ★3 이상은 화면 플래시 + 슬로모션 0.5초.

### 5-4. ⚒️ 폭발 강화 (핵심 와우 포인트)

기존 "+1씩 클릭" 방식을 버리고 **항상 여러 단계가 한 번에 오르는** 설계.

**규칙**

- 장비별 강화 +0 ~ +20. 1단계당 효과 +4% (★ 기본 효과에 곱).
- 단계별 💎 비용 = 2 + 현재단계 (누적 상승).
- **강화대는 보유 💎로 3단계 이상 올릴 수 있을 때만 활성화**(빛나기 시작).
  → 플레이어는 강화를 "자주 조금씩"이 아니라 "가끔 한꺼번에" 경험.
- 활성화된 강화대에서 버튼을 **누르고 있으면** 보유 💎를 전부 소모하며 가능한 최대 단계까지 연속 상승.
- 각 단계마다 **15% 확률 크리티컬** → 그 단계는 2배(+2) 상승. 크리티컬 시 화면 흔들림·황금 숫자.

**연출 시퀀스 (약 3~4초)**

1. 💎이 캐릭터에서 강화대로 소용돌이치며 빨려 들어감.
2. 망치가 내려칠 때마다 `+1 +2 +3 …` 숫자가 위로 튀고, 타격음 피치 계단 상승.
3. 장비에 단계별 오라 추가: +5 흰 빛 → +10 파란 불꽃 → +15 금빛 → +20 무지개.
4. 완료 시 ⚡ 파워 숫자 롤링 (예: `⚡ 120 → 187`), 카메라 살짝 줌인 + 흔들림, 캐릭터 3초간 오라.
5. 곧바로 밭으로 달려가면 **수확 속도 차이가 즉시 체감**되도록 강화대는 밭 옆에 배치.

**💎 강화석 공급 (1시간 기준 목표 ~200개)**

| 출처 | 양 |
|---|---|
| 레벨업 보상 | 약 140 |
| 작물 수확 시 1% 드롭(💎 튀어나옴) | 약 120~130 (60분 수확 1.2~1.3만 회) |
| 뽑기 중복 분해 | 가변 |
| 일일 상자 / Robux 상품 | 추가 |

→ 1시간 동안 폭발 강화 이벤트가 **약 5~6회** 발생하도록 튜닝 (Lv4, 6, 7, 8, 9, 10 부근).

### 5-5. ⚡ 파워 지표

- HUD 상단에 단일 숫자 ⚡. `= 이동속도% + 수확속도% + 운반량%` 합산 지수.
- 뽑기·강화·업그레이드 모두 이 숫자를 올림 → 성장의 단일 피드백 축.

| 게임패스 | 아이콘 + Robux 로고 | 준비중 | 🚧 |

### 6-2. 규칙

- 모든 가격 표기: `[아이콘] [💰] [숫자]`. 숫자는 1,000 → `1K`, 1,000,000 → `1M`.
- 등급은 색 + ★ 개수로만: 회색★ / 초록★★ / 파랑★★★ / 금색★★★★.
- 튜토리얼은 **유령 손가락 + 바닥 화살표 + 목표 오브젝트 하이라이트**로만 진행. 팝업 텍스트 없음.
- 버튼은 항상 아이콘 1개 + (있다면) 숫자 1개. 두 줄 이상 정보 금지.
- 확률 표기(정책): 뽑기 화면에 `★ 55%  ★★ 30%  ★★★ 12%  ★★★★ 3%` 숫자 노출.
- 색맹 대응: 등급 색과 ★ 개수를 항상 병기.

### 8-1. 게임패스 (영구) — 사용자 요청 "이동속도/수확속도 유료 아이템"

| 🎒✨ | 운반량 ×2 | 149 |
| 💰✨ | 코인 획득 ×2 | 299 |
| 🤖✨ | 전 구역 일꾼 속도 ×2 + 일꾼 1명 무료 | 249 |

### 8-2. 개발자 상품 (소모성)

| 아이콘 | 내용 | 가격(R$) 초안 |
|---|---|---|
| 💎 ×50 / ×300 | 강화석 팩 → 즉시 폭발 강화 가능 | 49 / 199 |

| ⏱️×2 | 15분 코인 ×2 부스트 | 29 |
| 🌱⚡ | 전 작물 즉시 성장 | 19 |
| 🔓 | 현재 게이트 즉시 해금 (스킵) | 게이트 가격 비례 |

### 8-3. 무료 보상 (광고 대체)

- 🎁 일일 상자: 접속 시 1회, 💎 10 + 🎫 확률.
- ⏱️ 타이머 상자: 20분마다 월드에 등장, 💎 5~15.
- 그룹 가입 보너스: 👟 +10% (Roblox 관례).

### 8-4. 정책 체크

- **Paid Random Items**: Robux로 구매 가능한 🎫는 확률 숫자 노출 필수. `PolicyService:GetPolicyInfoForPlayerAsync().ArePaidRandomItemsRestricted` 가 true인 플레이어에게는 🎫 Robux 판매 버튼 숨김 (무료 티켓 뽑기는 유지).
- 무료 티켓의 초반 리깅은 "유료 확률 표기"와 분리되어 정책 저촉 없음. 단, 확률 표기 옆에 🎁(무료) / R$(유료) 아이콘으로 구분.

## 11. 기술 설계 (Roblox / Luau)

### 11-1. 구조

```
ReplicatedStorage/
  Shared/Config/      ← 작물·패드·가챠·강화 수치 테이블 (ModuleScript, 데이터 드리븐)
  Shared/Icons/       ← 아이콘 ImageId 매핑
ServerScriptService/
  Services/
    PlotService       ← 플롯 할당·구역 상태
    HarvestService    ← 서버 권위 근접 수확 판정 (0.1s tick, 공간 그리드)
    EconomyService    ← 코인·XP·레벨
    GachaService      ← 리깅/천장/확률, 정책 체크
    EnhanceService    ← 폭발 강화 계산 (크리티컬 포함), 결과 일괄 전송
    ShopService       ← MarketplaceService 처리
    DataService       ← ProfileService 기반 저장 (세션락)
StarterPlayerScripts/
  Controllers/
    StackVisual       ← 머리 위 스택 렌더 (클라 전용, 서버는 count만)
    CoinVisual        ← 코인 파티클·자석 연출
    PadUI             ← 패드 게이지·아이콘 빌보드
    FXController      ← 강화/뽑기/레벨업 연출 시퀀스
    HUD
```

### 11-2. 핵심 결정

- **서버 권위**: 수확·판매·구매 판정은 전부 서버. 클라이언트는 위치만 보냄(기본 리플리케이션). 치트로 코인 조작 불가.
- **근접 판정**: 플롯별 작물을 4×4 stud 그리드 버킷에 저장, 플레이어 위치 버킷 ±1만 검사 → 6인 × 수백 작물도 저비용.
- **연출은 클라**: 서버는 `HarvestBatch {plotId, cropIds[]}`, `EnhanceResult {from, to, crits[]}` 같은 결과만 전송. 연출 시퀀스는 클라에서 재생.
- **데이터 드리븐**: 모든 수치는 Config 테이블. 밸런스 조정 시 코드 수정 없음.
- **저장**: ProfileService(세션락) + 자동 저장 60s + 퇴장 시 저장. 저장 데이터: 코인·💎·🎫·XP·구역/패드 단계·장비·강화 단계·뽑기 카운터(리깅/천장용)·구매 패스.
- **StreamingEnabled** 활성, 작물 메쉬는 단일 MeshPart 재사용 + 색만 변경.
- 도구: Rojo + Wally(선택). 아이콘은 Roblox 에셋 라이브러리 또는 자체 제작 플랫 아이콘.

## 14. 리스크 & 열린 질문

| 항목 | 리스크 | 대응 |
|---|---|---|
| 자동 수확 = 조작감 빈약 | "할 게 없다" 느낌 | 운반 한도·경로 최적화·나무 흔들기 등 **이동 자체를 퍼즐화** |
| 폭발 강화 텀이 길면 지루 | 💎 부족 | 수확 드롭률 3%를 데이터 보고 2~5% 사이 튠 |
| 초반 리깅이 기대치를 올려 이후 실망 | 2회차 꽝 | 3회차 ★2+ 보장, 천장 10회 |
| 아이콘만으로 이해 불가한 요소 | 성장속도💧 등 추상 개념 | 패드 옆에 효과가 눈에 보이는 미니 데모(작물이 빨리 자라는 루프 애니메이션) |
| 정책(랜덤 아이템) | 지역 제한 | PolicyService 분기, 무료/유료 뽑기 분리 |
| 6인 서버 성능 | 작물·코인 오브젝트 수 | 코인 풀링, 최대 코인 오브젝트 30개/플롯, 초과 시 합쳐진 큰 코인 |

**열린 질문**
1. 게임 정식 명칭 (아이콘 로고만으로도 인식 가능한 이름 권장. 예: 🌾⚡)
2. 4구역(가공소) vs 환생(Rebirth) 중 2차 스코프 우선순위
3. 펫(자동 수확 보조) 도입 여부 — Roblox 이용자 선호도는 높으나 아이콘 UI 복잡도 증가
4. 강화 실패/하락 요소 도입 여부 — 현재는 **실패 없음**(전연령·긍정 피드백 우선)
